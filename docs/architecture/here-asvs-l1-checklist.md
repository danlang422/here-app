# Here — ASVS Level 1 Working Checklist

Derived from OWASP ASVS v5.0.0 (Level 1 requirements only, ~70 of 345 total). Requirement IDs preserved for traceability back to the source standard — e.g. `v5.0.0-8.1.1`.

**Scope note:** Chapters below are included as a starting set. Some may turn out to be N/A once we look closer (flagged with a note). This is chapter-level scoping only — actual requirement-by-requirement applicability gets decided when we work each one.

**Type column:** `Documentation` requirements (per ASVS itself, always the first section of a chapter, though not every chapter has one) require an actual written policy to exist — the content lives in the companion doc, `here-security-decisions.md`, not in this table. `Implementation` requirements are verified directly against the code/config. Several Documentation requirements have a paired Implementation requirement in the same chapter that checks the policy is actually followed — e.g. v5.0.0-6.1.1 (documents the rate-limiting policy) pairs with v5.0.0-6.3.1 (verifies it's actually enforced).

**Evidence column:** per ASVS's own assessment guidance, a status label alone isn't verification — note *how* each item was checked (file/line reference, manual test performed, policy doc section, etc.), not just pass/fail.

Status values: `not started` / `in progress` / `verified` / `fixed` / `n/a`
